Overview

Built for competitive programmers who value simplicity

Testcase Generator eliminates the friction of creating test cases for competitive programming contests. Instead of wrestling with JSON configs or manual file creation, you define your problems in a natural folder structure.

The framework handles generation, validation, solution execution, and packaging — all deterministically reproducible with a single seed value.

spec.py 
from framework import *

spec = Problem(name="Two Sum", testcases=30)

N = Integer(name="N", min_value=2, max_value=100000)
Target = Integer(name="Target", min_value=1, max_value=10**9)
A = Array(name="A", size=N, min_value=-10**9, max_value=10**9)

spec.input(N, Target, A)

spec.add_testcases(
    minimum(),
    maximum(),
    random_case(),
    stress_case(),
    increasing(),
    decreasing(),
    boundary_values(),
)
Features

Everything you need, nothing you don't

A focused toolkit designed to solve one problem well: generating reliable testcases for competitive programming.

Folder-Driven Structure

Your contest organization IS your configuration. Create folders for contests and problems, add a solution.cpp, and you're ready to generate. No YAML, no JSON, no XML — just a natural directory hierarchy that mirrors how you think about problems.

LLM-Powered Specs

Provide a problem screenshot or description along with solution.cpp to your LLM using PROMPT.md. Get a complete spec.py generated automatically — no manual spec writing needed.

Deterministic Output

Same spec + same seed = identical testcases, every time. Reproduce results, debug issues, and verify correctness with confidence.

Rich Strategy Library

21+ built-in strategies for scalars, strings, graphs, and trees. From minimum/maximum edge cases to complex graph topologies like chains, stars, and balanced trees.

Custom Test Cases

Define your own test generators when built-in strategies aren't enough. Write a simple function, and the framework integrates it seamlessly into your test suite.

Automatic Packaging

Generates ready-to-upload ZIP files for HackerRank and similar platforms. Input/output pairs are verified and packaged automatically.

Quick Start

Up and running in minutes

Follow these steps to generate your first testcases.

Clone the repository

Get the framework on your local machine.

Create a contest folder

Organize your problems under a contest directory.

Add your solution

Place solution.cpp in the problem folder.

Generate spec.py

Provide the problem screenshot or description + solution.cpp to your LLM with PROMPT.md.

Run the generator

Execute the CLI and watch testcases appear.

terminal
$ git clone https://github.com/user/testcase-generator
$ cd testcase-generator
$ mkdir -p contests/MyContest/Problem_1
$ cp solution.cpp contests/MyContest/Problem_1/
$ python generate_tests.py contests/MyContest
Generation complete
